# JICA Schemes Dashboard

Dark (MetroTel Pulse) ArcGIS Dashboard for the 14 JICA irrigation + watershed schemes.

- Clean table: [`data/schemes_dashboard.csv`](data/schemes_dashboard.csv)
- Build steps: [`docs/JICA_DARK_DASHBOARD_BUILD.md`](docs/JICA_DARK_DASHBOARD_BUILD.md)

Join the table to your points (structures), lines (canal / WSM alignment), and polygons (command area / catchment) on `Scheme_UID`. Put all KPIs on a 14-row scheme layer, not on exploded structures.
