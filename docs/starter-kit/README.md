# Dashboard starter kit (from scratch)

Three downloadable files that match the tutorial standards:

| File | What it is |
| --- | --- |
| [Dashboard_Starter_Data.xlsx](Dashboard_Starter_Data.xlsx) | Publish-ready Excel. Sheet `CertifiedProperties` (48 WGS 1984 points) and sheet `PowerOutages` (30 points). Dropdown domains, real dates, six-decimal coordinates. |
| [01_From_Scratch_ArcGIS_Dashboard_Steps.docx](01_From_Scratch_ArcGIS_Dashboard_Steps.docx) | Click-by-click Word guide: this Excel → hosted layer → hosted view → web map → dashboard → actions → share. |
| [02_Excel_Data_Standards_and_Field_Descriptions.docx](02_Excel_Data_Standards_and_Field_Descriptions.docx) | Field catalog, coordinate rules, domains, and the pre-publish checklist. |

**Publish only** `CertifiedProperties` or `PowerOutages`. Do not publish `AllowedValues`, `DataDictionary`, or `ReadMe`.

In the ArcGIS Online wizard set **X = Longitude**, **Y = Latitude**, geographic CRS **WGS 1984**. US longitudes are negative.
