# Observer field card (laminate)

**Daily, 07:00**

1. Read rain gauge. Write mm. Empty the bottle.
2. If pond has water: read staff gauge to 1 cm. Take a photo of the numbers.
3. If water is over the red crest mark, write Overflow = Y.
4. If the pond is being pumped, write Pumped = Y (those days are not used for infiltration rate).
5. While the pond has water: measure W-N wells and *sarchah* with tape + float.

**haftewar / Weekly**

6. Measure all wells on the list, including control wells on the other fan.
7. At karez outlet: time a 10 or 20 L jerrycan. Q (L/s) = litres ÷ seconds.
8. If outlet is dry, write 0. Do not enter the tunnel.

**Rules**

- Same mark on the well rim every time.
- Never go to the gauge during a flood peak.
- If you miss a day, leave the row blank. Do not guess.
- Give the notebook to the technician each month.
