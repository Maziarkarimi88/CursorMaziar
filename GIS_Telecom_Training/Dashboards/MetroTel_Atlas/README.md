# MetroTel Atlas — light geo-marketing briefing

A second designed template: **warm paper, terracotta/sage**, with a **sidebar + hero ARPU + tall map + three bottom charts**. Same MetroTel Day 3/5 sample data as Pulse; different story emphasis (revenue first, actions in the rail).

Open `index.html` or `python -m http.server 8767`.

Native ArcGIS Dashboards: use a **light** theme, header off or minimal, left panel for selectors + list, one large indicator for ARPU, four small indicators, map right, three charts along the bottom. Colors in `agol/NATIVE_DASHBOARD.md`.
