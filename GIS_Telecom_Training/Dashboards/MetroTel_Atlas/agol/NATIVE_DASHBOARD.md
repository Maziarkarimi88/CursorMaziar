# Native ArcGIS Dashboards — Atlas (light)

Theme: **light**. Background `#F3EFE6`, panels white, text `#1B2430`.

| Token | Hex |
|---|---|
| P1 Expand | `#C45C26` |
| P2 Defend | `#2F6F5E` |
| P3 Fix QoS | `#B44A5A` |
| P4 Monitor | `#3D5A80` |

Layout:

1. Turn **header off** or keep only a title. Put **category selectors** in a left panel.
2. Left panel: selectors + **List** of decisions.
3. Main: one **large Indicator** (sum/avg ARPU) on the left; four small indicators stacked or 2×2.
4. Map takes the remaining right column (about 45% width).
5. Bottom row: pie (PRIORITY), serial bar (AVG_ARPU by DIST_NAME, horizontal if available), serial line (monthly table).

Actions: selector and list filter the map and indicators — same as Pulse, different composition.
