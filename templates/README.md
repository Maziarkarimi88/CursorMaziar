# Recharge calculator

`CheckDam_Recharge_Calculator.xlsx` is generated by `tools/build_protocol_assets.py`. Yellow cells are inputs; blue cells are formulas.

## Sheets

| Sheet | Matches | What you type | What it computes |
|-------|---------|---------------|------------------|
| README | — | nothing | colour key and dry-day rule |
| Site | Form A | dam ID, crest stage, catchment ha, Sy | used by other sheets |
| StageAreaVolume | Form A4 | stage (m), area (m²) | ΔV and cumulative V by trapezoid; crest V |
| FillAndHold | Form A6 | CN, C, E, infiltration | rainfall (mm) to fill 100%; days to empty from full |
| Evaporation | — | monthly E (mm/day) if you have a pan | lookup for DailyCalc |
| DailyPond | Form B | date, rain, stage, overflow Y/N, pumped Y/N | raw log |
| DailyCalc | — | nothing | A(h), V(h), dry-day flag, MDWIR, daily infiltration |
| Wells | Form C | date, well ID, class, DTW, rim elev | water elev, seasonal Δh, I4 |
| Karez | Form C | date, Q at *owkura*, optional control Q | flow days, mean Q, I5 |
| Summary | Form D | nothing | I1–I5 |
| Scorecard | Form D | final committee decision | YES/NO tests on I3/E, I4, I5 |

## Interpolation

DailyCalc converts stage to area and volume with linear interpolation on the StageAreaVolume table (MATCH/INDEX). Keep stages strictly increasing and include an exact crest row.

## Dry-day rule

A row is a dry day when rain = 0, overflow = N, pumped = N, and stage fell. Then:

```
infiltration_m3 = (V_previous - V_today) - E_mm/1000 × A_average
MDWIR_mm_d     = infiltration_m3 / A_average × 1000
```

On every other ponded day, infiltration = mean MDWIR × A_average. I1 is the sum of daily infiltration.

## Excel version

Needs Excel 2019 or later, or a recent LibreOffice Calc (MAXIFS / MINIFS on the Wells sheet). If MAXIFS is missing, compute min/max elevation per well by hand and type Δh into Wells column O.

## Example dataset

The generator loads a 30-day March–April filling on a 2.5 m crest pond. Independent Python values are written on DailyCalc!S6:S7 and Summary!B24:B26 so you can confirm the workbook matches.
