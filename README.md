# CursorMaziar

## InSAR with Python — self-learning course

A step-by-step, illustrated course on Synthetic Aperture Radar (SAR) interferometry with Python, built around Alexey Pechnikov's InSAR.dev and PyGMTSAR libraries and written for a curious 16-year-old.

- Read it here: [`insar-training/README.md`](insar-training/README.md)
- PDF version: [`insar-training/build/InSAR_Python_Training.pdf`](insar-training/build/InSAR_Python_Training.pdf)
- Figures are generated by `insar-training/scripts/make_figures.py`; the offline "InSAR in a shoebox" lab is `insar-training/scripts/lab0_toy_insar.py`; `insar-training/scripts/build_html.py` builds a single-file HTML.

```bash
cd insar-training
pip install -r requirements.txt
python scripts/make_figures.py
python scripts/lab0_toy_insar.py
python scripts/build_html.py
```
